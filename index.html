检测说明

浏览器安全限制说明：

由于浏览器的安全沙箱机制，本工具无法像原生应用那样直接访问系统底层的硬件信息。 我们通过以下方式获取信息：

  • WebGL调试信息 - 获取显卡型号和厂商信息
  • Navigator API - 获取CPU核心数和内存容量
  • UserAgent分析 - 识别操作系统和浏览器
  • 性能基准测试 - 评估硬件性能等级

如果需要更精确的硬件信息，建议使用专门的系统检测软件。
