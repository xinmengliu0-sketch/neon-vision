# 电脑性能检测网站

一个功能完整的电脑性能检测工具，无需安装任何软件，直接在浏览器中运行！

## 功能特性

- 🖥️ **硬件信息检测** - 自动检测并展示您的电脑配置（CPU、内存、显卡、存储等）
- ⚡ **性能测试** - 全面的性能测试（CPU运算能力、内存读写速度、图形渲染能力、存储I/O性能）
- 📊 **可视化报告** - 美观的性能分析报告，包含雷达图和详细指标
- 📜 **历史记录** - 自动保存测试结果，支持查看和对比历史记录
- 💡 **优化建议** - 根据测试结果提供个性化的优化建议
- 📱 **响应式设计** - 支持各种屏幕尺寸

## 快速开始

### 方法 1：直接打开（推荐）

无需服务器，直接双击打开即可使用！

1. 下载或克隆项目
2. 双击 `index.html` 文件
3. 在浏览器中开始使用

### 方法 2：使用本地服务器

```bash
# 使用 Python
python -m http.server 8000

# 或使用 Node.js
npx serve
```

然后在浏览器中访问 `http://localhost:8000`

## 技术栈

- 纯 HTML5 + CSS3 + JavaScript
- Chart.js - 数据可视化
- LocalStorage - 本地数据存储
- WebGL - GPU 信息检测

## 项目结构

```
neon-vision/
├── index.html          # 主页面
├── css/
│   └── style.css       # 样式文件
└── js/
    ├── hardware.js     # 硬件检测模块
    ├── benchmark.js    # 性能测试模块
    ├── storage.js      # 存储管理模块
    ├── charts.js       # 图表展示模块
    └── main.js         # 应用主程序
```

## 使用说明

1. **首页** - 查看硬件概览和最新测试结果
2. **硬件信息** - 查看完整的硬件配置详情
3. **性能测试** - 选择测试项目并开始性能测试
4. **历史记录** - 查看和对比历史测试结果
